Privacy notice

Threadseer is designed to analyze process data inside the Power BI custom-visual runtime without sending that operational data to the publisher.

Inside the Threadseer visual

Threadseer is a self-contained Power BI custom visual. It does not declare network privileges and does not transmit customer event data, field names, report names, process metrics, case identifiers, or visual telemetry to the publisher. Analysis begins through the explicit Analyze or Reanalyze workflow and derived snapshots remain in the visual runtime.

Power BI and the environment in which you run the visual are Microsoft products and remain subject to your organization’s configuration and Microsoft’s applicable terms and privacy statements.

This support website

This static site is hosted with GitHub Pages. The site contains no publisher-operated analytics, advertising, tracking pixels, contact forms, or external scripts. GitHub may process request and account information when it hosts this site or when you use GitHub; review the GitHub General Privacy Statement.

Public issues and private security reports

Information submitted to a GitHub issue is public and is processed by GitHub. Do not post personal data, employer event logs, report files, screenshots with case identifiers, tenant information, credentials, or proprietary field names. Use synthetic examples.

Suspected vulnerabilities should be submitted through GitHub private vulnerability reporting. GitHub account and service data remains subject to GitHub’s policies.

Changes

Material changes will be published on this page with a revised effective date. Earlier versions remain available through this public repository’s commit history.
